# Job Application Assistant

## Purpose

Own the canonical candidate-profile methodology and the workflow for evaluating, drafting, and preparing applications.

## Ownership

The numbered `01-*.md` through `09-*.md` files own their corresponding methodology topics. `SKILL.md` owns the workflow entry points and sequence.

## Local Contracts

- These files are the source of truth for candidate-profile and application-writing rules.
- Do not copy profile facts or detailed writing rules into app code, root `AGENTS.md`, or other skills. Link to the canonical file instead.
- Keep user-confirmed facts distinct from inferred information; follow the explicit evidence and approval rules in the relevant methodology.

## Work Guidance

When editing a numbered methodology file, check `SKILL.md`, affected commands, and generated hosted prompts. If hosted prompts derive from these files, update their build inputs rather than editing generated output.

## Verification

Use existing framework checks when requested. Confirm links and numbered-file references after structural changes.
