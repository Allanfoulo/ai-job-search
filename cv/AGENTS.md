# CV Sources

## Purpose

Own local CV source files and role-specific tailored CVs.

## Ownership

CV source files belong here. The canonical candidate profile remains in `CLAUDE.md` and `.claude/skills/job-application-assistant/`.

## Local Contracts

- Follow the canonical CV structure, evidence, and writing rules in `.claude/skills/job-application-assistant/`.
- Use the established filename pattern: `Role - Company - Candidate - Tailored CV.<ext>`.
- Do not invent candidate facts or overwrite existing CV sources without an explicit request.

## Work Guidance

Keep generated role-specific CVs traceable to their source and target application. Do not duplicate profile rules in local files.

## Verification

Use existing layout and PDF checks when requested.
